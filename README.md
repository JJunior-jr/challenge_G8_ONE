# challenge_G8_ONE

<h1>Descrição do projeto</h1>


<h2>Este projeto foi desenvolvido com base dos conteúdos do programa ONE (Oracle Next Education) em parceria com a Alura. A aplicação é de um  sorteios de amigo secreto trazendo tecnologia,  de forma rápida e prática, promovendo diversão e organização para grupos de amigos, famílias ou colegas de trabalho.</h2>

<h3>Funcionalidades</h3>
<h3>✔️ Sorteio de amigos secreto sem limite de participantes;</h3>

<h3>✔️ Impedir o sorteio de si mesmo</h3>
